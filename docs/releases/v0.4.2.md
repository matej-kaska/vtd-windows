**Leave VTD on. Dictate whenever you need it.** Version 0.4.2 is built to stay quietly in the tray all day, including from Windows startup. Hold F8 or tap F9, speak, and your words go straight into the active text field.

**About 0.1 MB of RAM while idle.** The speech engine loads when you record and exits after 30 idle seconds, releasing its RAM and VRAM. Normal dictation and last-transcript insertion now work reliably after the F9/F10 paste fix.

- **Idle after restart: 108 KiB (~0.11 MiB) private working set.** A local 30-second Windows sample ended at 264 KiB total working set and 1,020 KiB private committed memory, with zero CPU-time and disk-I/O deltas. Results vary with Windows and activity.
- The tray now uses a 22.5 KiB native resident. Settings, menus, microphone capture and model work run in temporary helpers, releasing their allocations when finished. The original icon is preserved.
- Fixed a helper crash during Ctrl+V that prevented F9/F10 insertion and could leave Ctrl pressed. Incomplete input sends now release the keys they pressed and restore the clipboard.
- Preserved existing models, preferences, custom shortcuts, autostart and playback muting. The complete package includes the new `vtd-helper.exe`.

Local validation: 24 unit tests, 16 resident integration cases and 10 interactive insertion/partial-send cases passed. Normal dictation was confirmed by the user. GitHub Actions builds and verifies the release assets; no tests run in the pipeline.

Download **VTD-Setup.exe** for installation or **vtd-windows-x64.zip** for portable use. Setup downloads the matching **vtd-runtime-x64.zip** and the selected model, checking SHA-256 hashes. For offline installation, keep the runtime ZIP beside setup and select an existing model. This release is unsigned.
